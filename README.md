# Editora Sintechtica

Site oficial da Editora Sintechtica, preparado para GitHub Pages e Supabase.

## Funcionalidades

- catálogo público de livros;
- pesquisa por título, autor e categoria;
- formulário de submissão editorial alinhado às 27 questões oficiais;
- resumo executivo automático em PDF, no papel timbrado, com as questões 7, 9, 11, 12, 13, 14, 16, 17 e 22;
- envio por e-mail do PDF e de uma cópia integral da obra;
- registro das propostas no Supabase;
- publicação automática com GitHub Actions.

Consulte `CONFIGURACAO.md` para instalar o banco, cadastrar os segredos e ativar o GitHub Pages.
